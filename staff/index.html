Rate card

Price per issue, per magazine, by ad size, number of zones and frequency. Both magazines use this card. More than 3 zones is worked out automatically: the 3-zone price plus the price of the extra zones, minus 15%.

Zones

Customers see the zone name, the areas it covers and the homes. Untick a magazine if it doesn't mail that zone.

Sold spots

Covers and one-per-zone positions (inside covers, page 3, centerfold) take one advertiser per zone per month. A booking here shows as Taken on the checkout. Delete a row if the booking is cancelled.

Connect the portal

Saving publishes your changes to the live checkout. Paste the access key your administrator gave you. You only need to do this once on each computer.

Administrator: how to create an access key
  1. Sign in to GitHub as the owner of the repository.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name it "Ad rates portal", pick an expiration, and under Repository access choose Only select repositories → this repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate it and give the key to staff who should be able to update rates.
